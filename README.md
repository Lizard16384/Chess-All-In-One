# Chess All In One

An All In One Minecraft command to create a fun little playable chess board!

Incredibly long command making use of [Payload](https://github.com/Lizard16384/Payload).

# How to use

I have done everything in my power to make this project as easy to use as possible. Just copy the command, grab an impulse command block, make sure it has some air above it, and set it to always active. The world will freeze for a good few seconds depending on the processing power of the server while the command is assembled from Payload, and then it might as well be a normal command, with the extra detail of its unnatural length.

You'll be greeted with a confirmation to either accept the placement and create the chess board or cancel it and start over elsewhere. If you confirm, you'll have a chess board now. Playing is done all with right clicking on the board, following standard chess legal moves and allowing movement as such. Clicking signs on the roof allow you to access the menu with more stuff to do with the board.
